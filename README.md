# phproom多场景通用计时计费系统
[点击了解详细功能](https://phproom.top)
【适用场景】 适配主机电玩店、拼豆手工坊、棋牌室、台球厅、桌游吧、私人影院、自习室、茶楼等各类按时计费门店。 
· 本地部署安装，门店数据本机存储：所有经营数据都保存在你自己的电脑里，不会上传云端，门店账目信息更安全，不怕泄露。 局域网环境下，手机、平板、浏览器均可登录查看后台，界面自适应屏幕。 
【核心功能清单】 
① 房态实时看板｜开台/加时/换房/暂停，一键结账，操作高效。 
② 自定义多档计费套餐，支持外接继电器联动控制店内灯光设备。 
③ 会员体系：充值储值、等级折扣、次卡券。 
④ 营业数据报表导出对账、超时语音提醒、桌台二维码自助查单、店内呼叫服务。 
⑤ 收银员交接班台账记录。
